# 데이터 전처리 자동화 전체 계획

2026-10-15 사용자가 대화의 전체 계획을 승인했다. 아래는 실행 계획이며 현재 진행 상태는 AI-brain GOALS.md를 따른다.

## 목표와 사용 흐름

표준 규칙 없이 여러 담당자가 작성한 쇼핑몰 데이터를 공통 규칙으로 정리하고, 애매한 항목은 근거와 함께 검토하도록 돕는다.

업로드 → 구조 확인 → 표준 컬럼 연결 → 품질 진단 → 규칙·미리보기 → 승인 실행 → 정제 결과·검토 대상·변경 이력 → 다운로드·규칙 재사용.

## 단계와 완료 기준

| 단계 | 산출물 | 완료 기준 |
|---|---|---|
| 1. 업무·데이터 정의 | schema.json, 데이터 사전, 업무 규칙 | 정상·오류·보류의 기준과 null 의미 설명 가능 |
| 2. 가상 데이터 | 기준 CSV 13개, 개발·평가용 오염, 비공개 평가 정답 | 관계·금액·시각 검증, 주입 오류 추적 가능 |
| 3. 진단 엔진 | 프로파일·문제 목록 | 원본 셀 위치와 문제 근거 추적 가능 |
| 4. 규칙 기반 처리 | 미리보기·승인 실행·규칙 버전 | 승인한 변경만 발생, 재실행 불변 |
| 5. AI 제안 | 컬럼·패턴·규칙 후보 | 유효한 규칙으로 검증, 불확실하면 보류 |
| 6. 서비스 화면 | 업로드~다운로드 웹 데모 | 코드 없이 전체 사용자 흐름 완료 |
| 7. 평가 | 수작업/규칙/AI 포함 비교 | 미사용 파일 정확도·오수정·검토시간·호출비용 측정 |
| 8. 포트폴리오 | 절차서·ERD·데모·평가·README | 주장마다 실제 산출물·검증 근거 연결 |

## 첫 서비스 범위

- CSV부터 시작, 고객·상품·SKU·주문·주문상세를 주요 처리 대상으로 삼는다. 나머지 8개도 기본 품질 검사를 지원하고 업무 상태 규칙은 순차 확장한다.
- 표준화: 전화·결측 표현·숫자·날짜·범주·컬럼명. PK/FK·금액 검증에서 출고/반품/환불 관계로 확장한다.
- 입력·원본 관리 / 진단 / 규칙·AI 제안 / 변환·검증 / 검토·출력 화면으로 역할을 나눈다.
- AI는 사전에 정의한 변환 기능 중 선택·제안한다. AI 자체 확신도만으로 실행하지 않는다.
- 문제 기록: 파일·행·컬럼·원본값·유형·근거·제안·자동 처리 가능 여부·규칙 버전·결과.
- 그룹별 승인 규칙을 재사용하고 새 패턴만 검토한다. 원본 불변, 변경 추적을 유지한다.
- 엑셀·메일·PDF/OCR, 외부 시스템 연동, 교환·재배송·재고는 후속 확장이다.

## 평가

- 개발에 쓰지 않은 파일에서 기존 패턴/새 패턴을 따로 집계한다.
- 컬럼 매핑 정확도, 문제 탐지 정밀도·재현율, 변환 정확도, 정상값 오수정률, 판단 보류 적절성, 관계·금액·수량 보존, 검토 포함 소요시간, AI 비용·지연.
- 수작업 비교는 난이도가 비슷한 별도 파일로 학습 효과를 줄이고 측정 조건을 남긴다.
- 목표 수치는 첫 측정 후 최종 평가 전에 고정한다. 가상 데이터 성능을 실제 현업 개선 효과로 주장하지 않는다.

## 일정 제안

1차 데이터·진단·규칙 처리 → 2차 AI·검토·재사용 → 3차 평가·개선·포트폴리오. 집중 작업 약 2~3주는 추정 범위이며 확정 마감이 아니다. 학술제와 병행 가능한 실제 작업시간에 맞춰 조정한다.
