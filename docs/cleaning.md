# 원본 보존 표준화 v1

AI 없이 데이터별 진단 설정의 표준화 후보만 새로운 CSV에 적용한다. 기존 진단 보고서를 입력으로 받지 않고 실행 시 원본을 다시 진단한다. 원본이나 MySQL에는 쓰지 않는다.

## 실행

```sh
cd ~/Developer/data-preprocessing-automation
uv run python scripts/clean.py data/dirty/development --config config/shop-diagnostics.json
```

`--output reports/cleaning/새이름`으로 새 결과 폴더를 지정할 수 있다. 기본은 실행별 고유 폴더다. 기존 폴더·원본 폴더와 그 하위 출력은 거부한다. 입력은 CSV 한 파일 또는 폴더, `--encoding`·`--delimiter`를 지원한다. 출력은 UTF-8/BOM 없음, 쉼표, LF이며 CSV 인용·줄바꿈의 바이트 표현은 달라질 수 있지만 헤더·행 순서·셀 문자열은 변경 내역대로 보존한다.

## 결과 파일

| 파일 | 용도 |
|---|---|
| data/*.csv | 정제한 13개 파일 등 입력별 새 CSV |
| changes.csv | 테이블·레코드·컬럼·원본·변경값·규칙 코드·원본 줄 위치·이유 |
| changes.json | 정확한 문자열, 논리 null, 적용한 컬럼 규칙 전체 포함 |
| before.json / after.json | 정제 전후 전체 진단, 설정·파일 해시·남은 문제 |
| after-summary.md | 정제 후 남은 항목의 네 분류 요약 |
| held.json | 같은 셀의 미해결 문제 때문에 보류한 후보 |
| manifest.json | 실행 상태·입출력 해시·실행 설정·변경 셀 수·검증 결과 |
| summary.md | 변화량과 결과 위치 요약 |

행 ID는 중복될 수 있으므로 원본 파일과 CSV 레코드 번호로 추적한다. 번호는 헤더 다음 행부터 1이며 물리 줄 위치를 별도로 보존한다. 여러 진단이 한 셀에 같은 제안을 하면 변경 내역은 한 건으로 합친다. 충돌하는 제안은 실행 오류다.

CSV에는 별도 null 자료형이 없으므로 허용된 NULL/없음 등은 빈 필드로 저장한다. changes.json의 before에는 원문, after에는 빈 문자열, logical_after에는 JSON null이 남는다. 빈 문자열과 논리 null의 구분이 필요하면 JSON 내역을 함께 사용한다. 변경 CSV를 스프레드시트에서 열 때 원문 보존을 위해 텍스트로 가져오는 것이 좋다.

## 검증과 보류

- 필수값·타입·범위 등을 통과한 표준화 제안만 적용한다. 같은 셀에 미해결 업무 위반/검토 문제가 있으면 보류한다. 동일 행 중복은 행 삭제 없이 보존하므로 다른 안전한 셀 표준화를 막지 않는다.
- 잘린 전화번호, 모호한 날짜, 수량 0, 참조 불일치 등을 추정해 채우지 않는다. 행 삭제·중복 병합·정답 데이터 조회를 하지 않는다.
- 임시 CSV를 재진단하여 신규 업무 위반·검토 항목·중복 그룹을 검사한다. 문제가 생기면 전체 실행을 실패로 남기고 data/를 발행하지 않는다. 실패 사유와 신규 항목은 validation-failure.json에 남는다.
- 전체 셀을 재읽어 원본과 변경 내역을 대조하고 헤더·행 수·원본 해시를 확인한다. 기존 문제는 해결했다고 표시하지 않는다.
- manifest.status=completed인 실행만 완료 결과다. 디스크 오류 등으로 failed가 되면 일부 파일이 있더라도 완료 결과로 사용하지 않는다. 기존 출력은 덮어쓰지 않으므로 재실행 시 새 폴더를 선택한다.
- 종료 0: 완료, 남은 업무 위반/검토 항목 없음. 종료 1: 완료했지만 기존 업무 위반/검토 항목이 남음. 종료 2: 설정·입력·검증·실행 실패.

검사는 구현된 진단 규칙 범위에 한정된다. 금액 합계·시간 순서 등 아직 구현되지 않은 업무 정합성을 보장하지 않는다. 소규모 CSV를 메모리에 읽는 구조이며 대량 스트리밍은 지원하지 않는다. 사용자에게 보이는 정제 미리보기 UI나 선택 적용 기능은 후속이다.

## 검증 실행 예

```sh
uv run pytest tests/test_cleaning.py -v
```

테스트는 원본/미변경 셀·null 원문·여러 줄 셀·앞자리 0 보존, 같은 셀 제안 합치기, 신규 중복/조건부 필수 위반 시 중단, 중복 키 변경 보류, 기존/원본 경로 거부, 잘못된 입력, 구분자/BOM, 재실행 무변경을 검사한다.
